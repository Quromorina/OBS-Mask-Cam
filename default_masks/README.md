# default_masks

インストーラに同梱する初期マスク画像の置き場です。

- ここに置いて **git にコミットした PNG だけ** が配布物に入ります（`OBSMaskCam_Installer.iss` の `[Files]`）。
- `masks/` は開発中の手元の画像置き場で、`.gitignore` の対象です。配布物には入りません。
- 画像が 1 枚も無くても問題ありません。アプリは初回起動時に `icon.ico` から標準のマスク（`icon.png`）を作ります。
- ここに置く画像は、再配布してよいもの（自作、または再配布可能なライセンスのもの）に限ってください。
